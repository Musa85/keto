# 🥑 كيتو — دليلي الشامل

دليل كيتو عربي شامل في **صفحة واحدة** تعمل بدون إنترنت وبدون سيرفر — كل شيء يُحفظ في متصفحك.

## 📖 المحتوى

| التبويب | الوصف |
|---------|-------|
| 🧭 **رحلتي والدليل** | المراحل الثلاث (صارم ← عادي ← لايف ستايل)، علامات دخول الكيتوزس، إنفلونزا الكيتو، دليل المسموح والممنوع، والتحويلات الذكية |
| 🧊 **وجبات التجميد** | ٤١ وصفة تُطبخ دفعة وتُجمّد حصصاً — مع تصنيف الرائحة (الخفيفة آمنة للتسخين في مكتب العمل)، وطريقة التسخين والتخزين لكل وصفة |
| 🍳 **طبخ مباشر** | ٤٠+ وصفة تُطهى وتُؤكل مباشرة: بيض، دجاج، لحم، مفروم، سمك |
| 🥗 **مكمّلات الوجبة** | سلطات، خضار جانبية (بدائل الأرز والبطاطس)، صلصات وغموس، وأمثلة تجميع وجبات جاهزة |
| 🥤 **سناكات البروتين** | ٣٧ وصفة على الآيزوليت واي والبيف بروتين + قائمة تسوق بتحذيرات الشراء |
| 🥜 **سناكات خفيفة** | ١٧ سناك سريع بين الوجبات بدون بروتين بودر |

## ✨ المميزات

- **عربي كامل (RTL)** بتصميم داكن دافئ
- **اختيار المرحلة** يلوّن الواجهة ويعدّل الدليل والفلاتر حسب مرحلتك
- **بحث وفلاتر** في كل قسم (نوع البروتين، الرائحة، الفرن/الموقد، نوع السناك…)
- **مفضلة ⭐** تُحفظ في المتصفح
- **ماكروز لكل وصفة** (سعرات، بروتين، دهون، كارب صافٍ)
- ملف HTML واحد — افتحه من أي جهاز أو ارفعه على أي استضافة ثابتة

## 🚀 الاستخدام

افتح `index.html` في المتصفح، أو زر النسخة المنشورة على GitHub Pages.
